# Планировщик для iOS

Личный планировщик задач для iPhone: один экран, бэклог под рукой, перетаскивание задач на время и между днями,
матрица Эйзенхауэра, быстрый ввод по‑русски, разбор просроченного одной кнопкой.

- План и решения: [`docs/PLAN.md`](docs/PLAN.md)
- Передача контекста между сессиями: [`docs/HANDOFF.md`](docs/HANDOFF.md)
- Интерактивный прототип: https://claude.ai/artifact/FaHx7HRgcbov9Kw9mHYFTh (исходник в [`prototype/`](prototype/))
- Правила для Claude Code: [`CLAUDE.md`](CLAUDE.md)

## Структура
- `PlannerCore/` — Swift‑пакет с чистой логикой без UI: парсер быстрого ввода, раскладка пересекающихся
  задач в колонки, планировщик свободных окон, сетка времени. Тесты запускаются на любой платформе: `swift test --package-path PlannerCore`.
- `App/` — приложение (SwiftUI + SwiftData), появится на этапе 1.
- `prototype/` — прототип экрана и скрипт его проверки.
- `docs/` — план и контекст.

## Как ведётся разработка
Код пишет Claude в облачной сессии и пушит в ветки; GitHub Actions собирает и прогоняет тесты.
На Mac: клонировать, открыть в Xcode, после «готово» сделать Pull (Integrate → Pull) и запустить на iPhone.
