# Очередь правок (по замечаниям с телефона, 21 октября)

Порядок — по важности: сначала то, что ломает работу, потом удобство, потом новое.

## Сборка 10 — стабильность (в работе)
- [x] Бэклог зависает на половине при свайпе и вешает приложение: высота «на весь экран» считалась от
      размера корневого стека, который сам растёт от панели — бесконечный цикл раскладки.
      Теперь размер берётся из GeometryReader (стабильный), стек не растёт.
- [x] Перенос из бэклога «улетает и прилипает»: при сворачивании панели ячейка List уничтожается
      вместе с распознавателем удержания. Жест перенесён на контейнер списка, строка определяется по рамке.
- [x] Бэклог в свёрнутом виде показывает две верхние задачи — тянуть можно не открывая.
- [x] Подтверждение удаления — по центру экрана, не поповером.
- [x] Строка задач без времени: сворачивается до одной + «+N», кнопка-стрелка вместо подписи «весь день».
- [x] Галочка «сделано» — тост с «Отменить» на несколько секунд.
- [x] «Просрочено»: тап по задаче открывает редактор, свайп влево удаляет, лист тянется до полного экрана.
- [x] Месяц: всегда шесть строк, клетки одной высоты.
- [x] Диктовка: деление по паузам в звуке убрано (резало внутри предложения).
- [x] Из ревью: рутина не удалялась целиком при правке расписания; удалённая задача не дописывается
      редактором; отмена жеста системой не считается сбросом.

## Сборка 11 — голос, матрица, проекты, свайпы
- [ ] Голос заново: слушает всё, по галочке — постобработка целого текста: чистка речевого мусора
      («ну», «короче», «мне нужно»…), деление по смыслу, короткие формулировки; карточки появляются после,
      их можно править. Умная чистка через Claude Haiku по своему ключу API (вводится в настройках,
      хранится в Keychain); без ключа — правила.
- [ ] Матрица: 2×2 + «Не разобрано» всегда целиком на экране (в клетке несколько задач и «+N»),
      тап по квадранту проваливается в полный список квадранта; при удержании задачи экран показывает
      пять контейнеров-целей; секции списка сворачиваются.
- [ ] Вид «Проекты»: колонки/секции по проектам, задачи перетаскиваются между ними.
- [ ] День: свайп влево/вправо листает дни; полоска недели свайпом листает недели (числа сверху остаются).
- [ ] Удобное переключение видов: кнопка-меню в углу (день / неделя / месяц, отдельно список и матрица),
      из месяца тап по дню → день, из недели → день, кнопка «назад» вверх по иерархии.

## Сборка 12 — месяц, календари, дашборд
- [ ] Месяц едет за пальцем при свайпе (без «затухания»), намёк, что можно листать, без лишнего места.
- [ ] Экспорт в Календарь Apple (EventKit; Google через аккаунт Google в iOS-календаре): свой календарь
      «Quick», задачи с временем — события, без времени — на весь день; правки и удаления синхронизируются.
- [ ] Дашборд по проектам: круговая диаграмма времени по проектам за день / неделю / месяц / год
      (дополнительный вид рядом с матрицей и списком).
- [ ] Оверлеи снизу (бэклог, просрочено) в одном стиле: тянутся до полного экрана, быстрые чистка и добавление.
