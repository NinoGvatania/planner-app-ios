# Очередь правок (по замечаниям с телефона, 21 октября)

Порядок — по важности: сначала то, что ломает работу, потом удобство, потом новое.

## Сборка 10 — стабильность (готово)
- [x] Бэклог зависает на половине при свайпе и вешает приложение: высота «на весь экран» считалась от
      размера корневого стека, который сам растёт от панели — бесконечный цикл раскладки.
      Теперь размер берётся из GeometryReader (стабильный), стек не растёт.
- [x] Перенос из бэклога «улетает и прилипает»: при сворачивании панели ячейка List уничтожается
      вместе с распознавателем удержания. Жест перенесён на контейнер списка, строка определяется по рамке.
      Сборка 22: заменено — жест снова на строке, список на время переноса держит высоту (рамки ячеек
      устаревали, новая задача не тянулась).
- [x] Бэклог в свёрнутом виде показывает две верхние задачи — тянуть можно не открывая.
- [x] Подтверждение удаления — по центру экрана, не поповером.
- [x] Строка задач без времени: сворачивается до одной + «+N», кнопка-стрелка вместо подписи «весь день».
- [x] Галочка «сделано» — тост с «Отменить» на несколько секунд.
- [x] «Просрочено»: тап по задаче открывает редактор, свайп влево удаляет, лист тянется до полного экрана.
- [x] Месяц: всегда шесть строк, клетки одной высоты.
- [x] Диктовка: деление по паузам в звуке убрано (резало внутри предложения).
- [x] Из ревью: рутина не удалялась целиком при правке расписания; удалённая задача не дописывается
      редактором; отмена жеста системой не считается сбросом.

## Сборка 11 — голос, матрица, проекты, свайпы (готово)
- [x] Голос заново: слушает всё, по галочке — постобработка целого текста: чистка речевого мусора
      («ну», «короче», «мне нужно»…), деление по смыслу, короткие формулировки; карточки появляются после,
      их можно править. Разбор только на устройстве: Apple Intelligence (FoundationModels), когда
      доступен и понимает русский, иначе правила с частями речи от NaturalLanguage.
- [x] Матрица: 2×2 + «Не разобрано» всегда целиком на экране (в клетке несколько задач и «+N»),
      тап по квадранту проваливается в полный список квадранта; при удержании задачи экран показывает
      пять контейнеров-целей; секции списка сворачиваются.
- [x] Вид «Проекты»: колонки/секции по проектам, задачи перетаскиваются между ними.
- [x] День: свайп влево/вправо листает дни; полоска недели свайпом листает недели (числа сверху остаются).
- [x] Удобное переключение видов: кнопка-меню в углу (день / неделя / месяц, отдельно список и матрица),
      из месяца тап по дню → день, из недели → день, кнопка «назад» вверх по иерархии.

## Сборка 12 — месяц, календари, дашборд (готово, проверить на телефоне)
- [x] Месяц едет за пальцем при свайпе (без «затухания»), намёк, что можно листать, без лишнего места.
- [x] Экспорт в Календарь Apple (EventKit; Google через аккаунт Google в iOS-календаре): свой календарь
      «Quick», задачи с временем — события, без времени — на весь день; правки и удаления синхронизируются.
- [x] Дашборд по проектам: круговая диаграмма времени по проектам за день / неделю / месяц / год
      (дополнительный вид рядом с матрицей и списком).
- [x] Оверлеи снизу (бэклог, просрочено) в одном стиле: тянутся до полного экрана, быстрые чистка и добавление.

## Сборки 15–17 — ревью, он‑девайс разбор, новая навигация (готово, проверить на телефоне)
- [x] Разбор диктовки только на устройстве (Apple Intelligence, иначе правила с NaturalLanguage).
- [x] Шапка: период (день/неделя/месяц/год) + режим (календарь/список/матрица/проекты/диаграмма), без «назад».
- [x] Один пейджер для всех видов, соседние страницы рядом; «Неделя списком» убрана.
- [x] Месяц: создание удержанием, перенос чипов. Год: мини‑месяцы.
- [x] Бэклог без кнопок: тап по панели открывает. Огонёк в шапке. Стекло на панели, призраке, досках.
