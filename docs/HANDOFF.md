# Передача контекста между сессиями

Проект начался в облачной сессии Claude Code (случайно запущенной в репозитории калькулятора `calc-pedant`;
туда ничего не записано). Всё наработанное перенесено сюда, в `planner-app-ios`.

## Что где
- `docs/PLAN.md` — план разработки: принципы, стек, модель данных, экран, жесты, парсер, этапы, открытые вопросы.
- `prototype/project/` — исходник интерактивного прототипа (формат `.dc.html` холста Claude Design):
  `Main.dc.html` — весь экран и вся логика (шаблон + класс на JavaScript), остальные файлы — сцены,
  которые импортируют `Main` с разным `scene`. `canvas.json` — раскладка холста.
  Холст: https://claude.ai/artifact/FaHx7HRgcbov9Kw9mHYFTh
- `prototype/harness/` — локальный прогон прототипа в Chromium (Playwright): 22 сценария взаимодействий
  и сканер наложений. Нужен файл `support.js` (рантайм холста, файл `artifact-type/dc-runtime.js` из артефакта),
  он не хранится в репозитории.
- `PlannerCore/` — Swift‑пакет: `QuickAddParser` (правила быстрого ввода, перенесены из `parse()` прототипа
  один в один), `DayLayout` (колонки для пересекающихся задач), `FreeSlotScheduler` (раскладка просроченных
  по свободным окнам), `ClockGrid` (минуты ↔ точки, шаг 15 минут, формат времени). Тесты — таблица фраз и кейсы.
- `CLAUDE.md` — правила проекта.

## Рабочий процесс
- Код пишется в облачной сессии Claude (там нет Xcode и Swift, компилировать негде), поэтому
  компилятор — GitHub Actions: `.github/workflows/ci.yml` гоняет тесты `PlannerCore` на Linux при каждом пуше,
  сборка iOS‑приложения на macOS‑раннере добавится вместе с `App/`.
- Работа идёт в ветках, в `main` попадает только зелёное.
- На Mac: `git clone`, открыть в Xcode, после сообщения «готово» — Integrate → Pull и ⌘R на iPhone.
  Установка на телефон без Mac невозможна (подпись); полностью без Mac — только Xcode Cloud + TestFlight
  при платном аккаунте разработчика.
- Макет ещё дорабатывается: правки сначала вносятся в `prototype/project/Main.dc.html` и публикуются на холст,
  потом переносятся в Swift.

## Решения по итогам ревью прототипа (не пересматривать без причины)
- Перетаскивание на тач‑экране только после удержания ~0,3 с; свайп по задаче = прокрутка.
- Квадрант — отдельное поле задачи, цвет выводится из него.
- Сетка дня 0:00–24:00, экран открывается на текущем часе.
- Захваченная точка блока сохраняется при переносе; шаг 15 минут; конец дня «24:00».
- Заголовки нигде не режутся молча: перенос на 2 строки + многоточие.
- Все цели нажатия ≥ 44 pt, текст ≥ 11 pt.
- Сделанная задача в бэклоге остаётся видна зачёркнутой (пока включено «показывать выполненные»).
- Рутины не попадают в «Просрочено» и в матрицу.

## Проверка прототипа
Chromium + Playwright: 22 сценария проходят, сканер наложений чист, ошибок в консоли нет.
Независимый обзор (4 линзы, 32 находки, 26 подтверждены перекрёстной проверкой) — все исправлены.

## Устройство и аккаунт
- iPhone 15 Pro Max, минимальная iOS — 26 (iPhone 11 и новее).
- Бесплатный Apple ID: установка с Mac из Xcode, переустановка раз в 7 дней, без iCloud и TestFlight.
- Приложение только для себя, синхронизация не нужна.
