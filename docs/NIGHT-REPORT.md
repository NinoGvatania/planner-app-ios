# Отчёт за ночь 20→21 октября

Всё ниже лежит в `main` и собрано GitHub Actions (сборка № видна в меню вида, пункт «Сборка N»).
Обновить на телефоне: в терминале `cd ~/planner-app-cloud && git pull`, затем в Xcode ⌘R.

## Что сделано
- **Бэклог открывается.** Причина: список панели при свёрнутой высоте 0 pt всё равно занимал свои
  300 pt и невидимо лежал поверх заголовка и строки ввода, перехватывая тапы и свайпы.
  Теперь список занимает ровно отведённое место; свайп считается в координатах экрана;
  открытая панель не выше свободного места (с клавиатурой — ниже); под строкой ввода нет пустого поля.
- **Сетка дня**: подписи часов выровнены с блоками (были на ~20 pt ниже); у выделенного блока две ручки —
  нижняя меняет конец, верхняя — начало; у края экрана сетка прокручивается сама при перетаскивании
  и растягивании; тап по пустому месту создаёт задачу на 30 мин, удержание с протягиванием — нужной
  длины (просто удержание без движения ничего не создаёт); перетаскиваемый блок не теряется,
  когда полоска недели переключает день; карточка под пальцем не уезжает за край экрана.
- **Виды**: День, **Неделя сеткой** (семь колонок с понедельника, свайп по заголовкам листает недели),
  Неделя списком, **Месяц** (своя интерпретация: чипы цветом квадранта, «+N», тап по дню открывает его,
  свайп листает месяцы, в клетки можно бросать задачи), Матрица с полкой «Не разобрано».
- **Цвета**: серый = не разобрано (квадрант не выбран) — так выглядит новое в бэклоге и из быстрого ввода
  без слов «важно/срочно»; зелёный = «не важно, не срочно». В редакторе появился пункт «Не разобрано».
- **Редактор задачи** (второй тап по выделенному блоку, тап по строке в бэклоге/матрице/неделе):
  название, день, «весь день», начало, длительность, квадрант, проект, галочка, рутина, удаление.
- **Голосовой ввод** по образцу Todoist, только на системном распознавании Apple (ru-RU): экран диктовки,
  карточки задач появляются по ходу речи, пауза → карточки можно править (тап) и удалять (крестик),
  «Ещё» продолжает диктовку, «Готово» сохраняет. Деление по паузам, точкам, «а ещё/потом», «и» между
  двумя действиями; внутри куска работает парсер быстрого ввода (день, время, «важно», `#проект`).
- **Рутины**: переключатель в редакторе создаёт шаблон и копии на неделю вперёд; копии досоздаются
  при запуске и возврате в приложение.
- Просрочено с переносом, уведомления, быстрый ввод — как было.

## Что не проверено на устройстве (нет симулятора в облаке)
- Голосовой ввод целиком: запрос разрешений (микрофон, распознавание), качество деления на задачи,
  поведение при лимите системы (~1 минута на заход — заход перезапускается сам).
- Автопрокрутка у края и верхняя ручка: ощущение скорости (12 pt за кадр, зона 52 pt — как в прототипе).
- Неделя сеткой на 7 колонках: читаемость узких блоков (11 pt, без кружка).
- Месяц: высота клеток на 6-недельном месяце, число чипов.
- Клавиатура + открытый бэклог: панель должна ужиматься, а не уезжать под Dynamic Island.

## Известные ограничения
- Старые задачи на телефоне с квадрантом «серый» теперь считаются «не важно, не срочно» (зелёные):
  серый остался только для новых неразобранных. Если нужно, удалить приложение и поставить заново —
  данные демонстрационные.
- Деление диктовки — правила, не модель: «купить хлеб и молоко» одна задача, «позвонить маме
  и купить хлеб» — две; необычные фразы лучше диктовать с паузами или точками.
- Напоминания — только локальные, за 0 минут до начала задачи с временем.

## Утренний чек-лист
1. `git pull`, ⌘R; в меню вида убедиться, что «Сборка» ≥ 6.
2. Бэклог: тап по заголовку открывает/закрывает; свайп вверх/вниз тянется за пальцем; с клавиатурой
   панель не уезжает за верх экрана.
3. День: подписи часов совпадают с блоками; тап по блоку — две ручки; верхняя двигает начало,
   нижняя — конец; тянуть к краю — сетка едет сама; второй тап — редактор.
4. Тап по пустому месту — «Новая задача» с запросом названия; удержание + протягивание — силуэт и задача
   нужной длины; удержание без движения — ничего.
5. Перетащить задачу из бэклога на сетку, на вкладку дня (подержать — день откроется), обратно в бэклог.
6. Неделя: семь колонок, свайп по заголовкам; бросить задачу в другую колонку.
7. Месяц: тап по дню → День; свайп → соседний месяц; бросить задачу из бэклога в клетку.
8. Матрица: серые на полке «Не разобрано», тянутся в квадранты и обратно; четвёртый квадрант зелёный.
9. Голос: микрофон → разрешения → сказать «Позвонить маме. Завтра в 10 созвон, важно. Купить хлеб и молоко» →
   три карточки; пауза → тап по карточке → поправить; крестик → удалить; «Ещё» → добавить; «Готово».
10. Редактор: включить «Ежедневная рутина» у задачи с временем — копии появляются на неделю вперёд.
