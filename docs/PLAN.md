# Планировщик для iOS — план разработки

Личный планировщик вместо Todoist: один экран, минимум полей, быстрый ввод по‑русски,
бэклог под рукой, перетаскивание задач на время и между днями, матрица Эйзенхауэра,
разбор просроченного одной кнопкой. Интерактивный прототип (веб, на холсте Claude):
https://claude.ai/artifact/FaHx7HRgcbov9Kw9mHYFTh — исходник в `prototype/project/Main.dc.html`.

## Принципы
- Один экран. Сверху дата, кнопка «Просрочено» (появляется только когда есть просроченные),
  переключатель вида и «к сегодня». Никакого таббара.
- Задача = название + (день, время, длительность) + квадрант. Всё остальное опционально и скрыто.
- Ввод одной строкой по‑русски; голос — та же строка, только надиктованная.
- Бэклог — выдвижная панель снизу: новые сверху, старые снизу. Из неё задачи тянутся на расписание.
- Цвет задачи = квадрант Эйзенхауэра, одинаково во всех видах:
  красный — важно и срочно, жёлтый — важно, синий — срочно, зелёный — не важно и не срочно.
  Серый — задача ещё не разобрана (квадрант не выбран): так выглядит новое в бэклоге.
  Настройка «Цвет задач» в меню вида переключает на цвета проектов (без проекта — серый).
- Проекты: метка + цвет из палитры (10 цветов). Лист «Проекты…» в меню вида: добавить, переименовать,
  выбрать цвет, удалить (задачи остаются без проекта).
- Ежедневные рутины никогда не считаются просроченными.

## Стек
- Swift 6, SwiftUI, SwiftData. Сторонних библиотек нет.
- Минимальная iOS — 26: iPhone 11 и новее (чип A13+), включая SE 2020/2022; XS/XR/X не поддерживаются.
  Основное устройство — iPhone 15 Pro Max.
- Аккаунт разработчика бесплатный (личная команда Xcode): установка только с Mac из Xcode, приложение живёт
  на телефоне 7 дней, потом снова ⌘R; iCloud/CloudKit, push и TestFlight недоступны.
- Хранение только локальное (SwiftData); данные попадают в обычный бэкап iPhone.
- Распознавание речи: `SFSpeechRecognizer` (ru-RU): `SpeechAnalyzer` iOS 26 русский не поддерживает.
- Свободные голосовые команды («перенеси просроченные на вечер»): облачная модель Claude Haiku 5.5
  через маленький свой сервер (ключ не хранится в приложении). Встроенная модель Apple не подходит:
  русского нет в списке поддерживаемых языков Apple Intelligence (проверить перед стартом этапа).

## Модель данных (SwiftData)
```
Task
  id: UUID
  title: String
  day: Date?            // календарный день; nil = бэклог
  start: Int?           // минуты от 0:00; nil = «весь день»
  duration: Int         // минуты, шаг 15, по умолчанию 30
  quadrantRaw: Int      // 0 не разобрано (серый), 1 красный, 2 жёлтый, 3 синий, 4 зелёный
  isDone: Bool
  isRoutine: Bool       // ежедневная рутина
  project: Project?
  backlogRank: Int      // убывает = новее; меняется при каждом возврате в бэклог
  createdAt, completedAt: Date
Project { name (уникально), colorIndex }  // цвет из палитры ProjectPalette
Routine { id, title, start, duration, quadrant, weekdays }  // шаблон, порождает Task на день
```

## Экран
- **Шапка**: «20 октября / Сегодня, вторник», кнопка «Просрочено · N», кнопка вида, кнопка «сегодня»
  (квадрат с числом сегодняшнего дня: возвращает к сегодня и в «Дне» прокручивает к текущему часу).
  Все кнопки ≥ 44 pt.
- **Виды** (переключаются меню из кнопки вида): День, Неделя (сетка), Неделя списком, Месяц,
  Матрица Эйзенхауэра. В меню же тумблер «Показывать выполненные» и номер сборки.
- **День**: полоска недели (7 вкладок от сегодня; если выбран день дальше — неделя с понедельника),
  строка «весь день», сетка 0:00–24:00 (час = 56 pt), линия текущего времени, блоки задач;
  пересекающиеся задачи встают в колонки.
- **Неделя**: семь колонок с понедельника, заголовки дней — зоны сброса, свайп по заголовкам листает
  недели; в узких блоках только название (без кружка).
- **Неделя списком**: 7 секций по дням, каждая секция — зона сброса.
- **Месяц**: недели с понедельника, в клетке число и чипы задач цветом квадранта, «+N» если не влезло,
  сегодня — акцентный кружок; тап по дню открывает его в «Дне», свайп влево/вправо листает месяцы,
  клетка — зона сброса (день меняется, время сохраняется). Своя интерпретация Apple/Google Calendar.
- **Матрица**: два режима. «Матрица» — 2×2 квадранта, каждый растёт под свои задачи, страница
  прокручивается целиком; «Список» — четыре секции по убыванию приоритета, все задачи видны.
  Квадранты и секции — зоны сброса. Под ними полка «Не разобрано»: серые задачи без квадранта.
- **Бэклог**: панель снизу, три положения — свёрнута (112 pt: заголовок + строка ввода + микрофон),
  открыта (до 6 строк) и на весь экран. Тап по заголовку переключает, свайп тянет за пальцем и
  отпускает к ближайшему положению. Строки: тап — редактор, удержание — перенос, свайп влево — удалить.

## Жесты (точно как в прототипе)
- Тап по блоку — выделение: белая рамка, две ручки (сверху и снизу), в блоке «14:30–16:00 · 1 ч 30 мин».
  Нижняя ручка двигает конец, верхняя — начало (конец на месте), шаг 15 мин, у края экрана сетка
  прокручивается сама, пересечения перестраиваются в колонки сразу. Конец дня пишется «24:00».
  Второй тап по выделенному блоку (или тап по ручке без движения) открывает редактор задачи.
- Перетаскивание на тач‑экране — после удержания ~0,3 с (иначе свайп по задаче прокручивает экран).
  Реализация — UIKit‑распознаватель `UILongPressGestureRecognizer` через `UIGestureRecognizerRepresentable`
  (`HoldDragGesture`): связка SwiftUI `LongPressGesture` + `DragGesture` внутри ScrollView перехватывает прокрутку.
  Пока тянешь: карточка под пальцем, пунктирный силуэт на сетке с точным временем,
  шаг 15 мин, захваченная точка блока сохраняется (блок не прыгает верхом к пальцу).
- Задержка над вкладкой дня в полоске недели ~0,4 с — открывается этот день, можно везти дальше на час.
  Сброс прямо на вкладку = «весь день» этого дня.
- Сброс на панель бэклога — задача уходит в бэклог наверх списка.
- В матрице перетаскивание между квадрантами меняет квадрант (и цвет) задачи.
- Брошенная на сетку задача сразу выделяется — можно тут же растянуть.
- Свайп/тап по заголовку панели бэклога открывает и закрывает её; прерванный свайп не «съедает» следующий тап.
- Удержание на свободном месте сетки создаёт задачу на 30 мин в этом месте (с запросом названия);
  удержание с протягиванием вниз — задачу нужной длины (силуэт с временем, пока тянешь).
  Тап по свободному месту только снимает выделение (тап-создание убрано: слишком много случайных задач).

## Голосовой ввод (расшифровка целиком, потом разбор)
- Микрофон в строке бэклога открывает экран диктовки: говоришь всё подряд, на экране растёт
  расшифровка. Распознавание — `SFSpeechRecognizer` (ru-RU, с пунктуацией), без серверов.
  Пауза останавливает микрофон и даёт поправить текст, микрофон продолжает.
- По галочке весь текст разбирается на задачи постобработкой (`TaskExtractor`):
  - с ключом Claude API (вводится в «Настройки…», хранится в связке ключей): модель делит по смыслу,
    убирает речевой мусор, формулирует коротко, понимает день, время, длительность, «важно/срочно»,
    проект; ответ строго по JSON‑схеме; модель на выбор (Haiku 5.5 по умолчанию, Sonnet 5.5, Opus 5.5);
  - без ключа или без сети — правила: `DictationSplitter` (точки, «точка», «следующая», «а ещё»,
    «потом», «и» между двумя действиями) + `SpeechCleanup` (убирает «ну», «короче», «мне нужно»…)
    + парсер быстрого ввода для дня, времени, квадранта, `#проекта`.
  Паузы по уровню звука текст не делят (это резало фразы на куски); пауза дольше трёх секунд между
  словами даёт перенос строки — подсказка для разбора, не жёсткая граница.
- Карточки после разбора: тап — лист правки, крестик — удалить, микрофон — надиктовать ещё
  (карточки добавляются к уже разобранным), галочка сохраняет: без дня — в бэклог, с днём — на сетку.
- `SpeechAnalyzer` (iOS 26) не используется: русского нет среди поддерживаемых языков.

## Рутины
- Переключатель «Повторять» в редакторе задачи создаёт шаблон `Routine` по её названию, времени и
  длительности и копии на 7 дней вперёд; выключение удаляет шаблон и будущие невыполненные копии.
  Расписание: дни недели (чипы пн…вс), каждую / нечётные / чётные недели года. Время и длительность —
  из задачи, их правка переносится в шаблон. Шаблон помнит, по какой день копии созданы: удалённая
  копия не возвращается. При запуске и возврате в приложение копии досоздаются.

## «Просрочено» (как в Todoist, но удобнее)
- Кнопка в шапке → лист со списком просроченных, галочки прямо в нём.
- «Перенести»: «На сегодня — в свободные окна» (с ближайшего четверти часа, важные первыми,
  что не влезло — в бэклог), «На завтра» (с 9:00), «В бэклог».
- После раскладки экран переключается в «День» и прокручивается к первой поставленной задаче.

## Быстрый ввод (правила разбора, реализованы в прототипе — перенести 1:1)
- Дата: сегодня / завтра / послезавтра / «в пятницу» (ближайшая будущая).
- Время: «в 9:30», «в 9.30», «в 10», «в час дня», «в 12 ночи», «утром/днём/вечером/ночью»
  (без числа → 9:00 / 14:00 / 19:00 / 23:00; с числом — задают половину суток: «вечером в 7» = 19:00).
  Число 1–6 без уточнения считается послеполуденным («в 5» = 17:00).
- Длительность: «на полчаса», «на полтора часа», «на 45 минут», «на 2 часа», «на час».
- Квадрант: «важно/срочно/не важно/не срочно» в любой форме («важное срочное», «срочняк»), `!1`–`!4`.
- Проект: `#учёба`.
- Знаки препинания после слов не ломают разбор; «но/и/а» на краях убираются из названия.
- Если времени нет — задача в бэклог. Ответ пользователю: ««Созвон» — завтра · 10:00–10:30 · важно и срочно».
- Команды: «что у меня завтра», «перенеси просроченные на сегодня/завтра».

## Дизайн‑токены (из прототипа)
- Фон `#0E0F11`, панели `#17181B`/`#1A1B1E`, текст `#F3F4F6`, подписи `#A1A1AA`, акцент мятный `#3EE0A6`.
- Квадранты: красный `#FF6159` на `#3A1D1B`, жёлтый `#FFC53D` на `#3A2E12`,
  синий `#5E9EFF` на `#18263D`, зелёный `#5CCB6E` на `#162B1C`. Не разобрано: серый `#8C8C96`
  на `#232429`. Просроченная дата `#FF7A70`.
- Шрифт системный (SF Pro). Минимальный размер текста 11 pt. Цели нажатия ≥ 44 pt.
- Скругления: блоки 9, карточки 14–16, панели 22–26.

## Этапы
0. Подготовка: репозиторий, CI, пакет `PlannerCore`, Xcode‑проект, SwiftData‑модель — готово.
1. MVP: день, бэклог с быстрым вводом, перетаскивание, выделение и растягивание, галочки,
   «Просрочено» с переносом, локальные уведомления, создание тапом по сетке, редактор — готово.
2. Удобство: неделя сеткой, неделя списком, месяц, матрица с полкой «Не разобрано», рутины,
   диктовка голосом — готово.
2a. Навигация и виды (сборки 11–14): свайпы между днями / неделями / месяцами (страница едет
   за пальцем), «назад» вверх по иерархии месяц → неделя → день, заголовок‑меню видов; матрица
   целиком на экране с проваливанием в квадрант и доской целей при удержании; вид «Проекты»
   с переносом между проектами; дашборд (круговая диаграмма времени по проектам); экспорт
   в Календарь (EventKit, свой календарь «Quick» или календарь Google‑аккаунта); серия дней
   (огонёк); виджет «Сегодня»; иконка и имя Quick; Liquid Glass в шапке и кнопках — готово в коде,
   проверяется на телефоне.
3. Без открытия приложения: Siri/«Команды» и кнопка действия («добавь задачу …»),
   текущая задача в Dynamic Island.
4. Свободные голосовые команды — сделано прямо из приложения по своему ключу Claude API
   (см. «Голосовой ввод»); свой сервер не нужен.
5. iCloud‑синхронизация и iPad/Mac — только если появится платный аккаунт разработчика.

## Решено
- Телефон: iPhone 15 Pro Max (есть кнопка действия). Минимальная iOS — 26.
- Apple ID бесплатный, приложение только для себя: без App Store, без iCloud, установка с Mac.
- Синхронизация между устройствами не нужна.
- Сборку и тесты гоняет GitHub Actions; код пишется в облачной сессии Claude; на Mac — Pull и ⌘R.
